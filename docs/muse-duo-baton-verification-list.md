# μ's DUO バトンタッチ効果の限定修正

2026-11-03。対象は下記2レアリティの登場能力だけ。μ's DUO全商品の監修完了ではない。

| 状態 | 番号 | ID | 名前 | 主テンプレート | 備考 |

- 正本は `data/cards.json`。総合ルール1.3.2（可能な処理を実行）、9.6.2.3.2（バトンタッチ）、9.6.3.1（公開領域の固定枚数選択）を参照。
- 旧処理は `grant_jouji_session` へ潰れ、回収とバトンタッチ人数・グループ・コスト合計条件が欠落していた。
- 新分類はカード番号に依存せず、能力文から人数・グループ・回収フィルタ・コスト合計・スコアを抽出する。
- バトン元の情報を退場前に複製し、自動効果で領域移動しても条件を保持する。退出時に消去し、再登場へ持ち越さない。
- 回収対象なしでも「さらに」の独立したスコア条件を解決する。合計14/16でも条件を満たすライブカードの回収は行う。
- 固定1枚の公開領域回収ではキャンセルによる省略を防止し、対象選択を維持する。任意選択の既存ダイアログは従来通りキャンセル可。
- 全データの類似文言を検索。完全同型は上記2枚。Liella! bp4-004の4レアリティは別のドロー／登場効果なので、本テンプレートへまとめない。
